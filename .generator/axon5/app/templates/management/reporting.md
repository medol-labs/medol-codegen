# Reporting

Import `reporting` into the backend that owns its read models, and include `Reporting` in the frontend. Register `ReportProvider` beans in your hand-written infrastructure package. Provider keys must be unique. No SQL, connection credentials, or executable code is accepted from users.

Providers declare versioned parameter/column contracts and an implementation fingerprint. The generated definition form manages Draft → Published → Retired versions. Publication freezes the contract. Changed parameters, column meaning, or query semantics require a new version. Existing providers must remain installed for old task authorization. Authorization must load the current identity and enforce row and column permissions for QUERY, EXPORT and DOWNLOAD, including background execution without an HTTP security context.

The definition detail page provides typed parameter inputs, bounded table queries and CSV export. Integer and decimal inputs preserve their JSON numeric text. The browser preview uses JavaScript numbers; use STRING columns when exact high-precision presentation is required. Exports preserve server numeric text.

`query` returns at most the requested limit with `hasMore` and a source version/freshness description. `openExport` returns an AutoCloseable stream, empty batch means EOF. Provide stable ordering and close the read-only transaction/connection. Set database statement timeouts; the worker cannot interrupt an arbitrary blocked provider. `SNAPSHOT` means all batches share one actual consistent snapshot. `EVENTUAL` must not be represented as a historically reproducible result. Cross-database queries and projection-watermark checks belong to the provider. Do not query aggregates or scan event stores for each report.

Enable workers using `medol.reporting.enabled=true` (default false). Configure `medol.reporting.storage-path` (default `build/reports`) to a persistent shared volume on all instances. The volume must support atomic directory moves and directory fsync. Jobs, private inputs, management history/outbox and report files must be backed up together. Do not remove a file referenced by a Completed job. Unreferenced attempt directories and abandoned staging directories may only be cleaned after confirming no worker is using them.

Exports run asynchronously: Requested → Processing → Completed/Failed. Claim leases last ten minutes; runtime checks a five-minute budget between batches. Explicit retries accept Failed or expired Processing, require the owner and current permissions, and reread the data. There is no automatic retry or claim that input parameters reproduce old results. Attempts are fenced by unique tokens so stale workers cannot publish results after retry. Definitions can retire after acceptance; accepted jobs retain their definition. A changed provider fingerprint blocks the old job.

Limits: 30 parameters, 100 columns, 64 KiB parameter JSON, 200 rows per preview page, offset at most 10000, one million exported rows, 128 MiB CSV. CSV uses UTF-8, quoted cells, CRLF and spreadsheet-formula neutralization. Output is atomically published and SHA-256 checked before download. Output size/time excess fails the task; no silently truncated reports.

Endpoints under `/api/reports`: `/{versionId}/contract`, `POST /{versionId}/query`, `POST /{versionId}/exports`, `/{versionId}/executions`, `/executions/{id}`, `POST /executions/{id}/retry`, `/executions/{id}/file`. Query permission: `report_definition_catalog:read`; export/status/download: `request_report_execution:execute`; retry: `retry_report_execution:execute`; the existing `*:*` administrator grant also applies. Provider checks apply even to administrators. Task APIs are owner-scoped; no unrestricted execution read model is generated. Task inputs, query rows and CSV contents do not enter public modeled events. Query audit means query completed; download audit means download authorized, not delivery acknowledged.

Management definitions and execution state are JDBC authoritative with transactional outbox to Axon events and optional operation-audit. This is not Axon event-sourced task storage. First release rejects tenant-management combinations. It does not include BI dashboards, arbitrary SQL, XLSX/PDF renderers, automatic schedules, or archive unions. Those integrations remain explicit business adapters.
